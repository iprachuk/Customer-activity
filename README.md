# Customer Activity Analysis

## Опис проєкту

Цей репозиторій містить комплексний аналіз активності користувачів, включаючи їхні облікові записи, взаємодію з електронною поштою та географічний розподіл по країнах.

## Основні компоненти

### 📊 **SQL запити для аналізу**
- **analysis_of_user_activity** - розширений SQL запит для аналізу:
  - Активності користувачів за країнами та датами
  - Метрик облікових записів (кількість створених акаунтів, верифікація, статус підписки)
  - Метрик електронної пошти (кількість відправлених, відкритих та проглянутих повідомлень)
  - Рангування країн за активністю користувачів та об'ємом email-комунікацій
  - Топ-10 країн по різноманітним показникам

### 📁 **Залучені таблиці даних**
- `DA.account` - інформація про облікові записи (інтервал відправки, верифікація, статус підписки)
- `DA.account_session` - зв'язок між обліковими записами та сесіями
- `DA.session` - дані про сесії та дати створення
- `DA.session_params` - параметри сесій (включаючи країну)
- `DA.email_sent` - дані про відправлені email повідомлення
- `DA.email_open` - дані про відкриті email повідомлення
- `DA.email_visit` - дані про клікнення в email повідомленнях

### 📈 **Ключові метрики**
- Кількість створених облікових записів по країнах
- Рівень верифікації користувачів
- Активність email-комунікацій (відправлення, відкриття, клікнення)
- Статус підписки користувачів
- Географічний аналіз та рангування країн

### 📄 **Документація**
- **Customer_activity.pdf** - детальний звіт з аналізом активності клієнтів

## Технічні особливості запиту

Запит використовує передові SQL техніки:
- **CTE (Common Table Expressions)** - модульна структура з 4 CTEs для розділення логіки
- **UNION ALL** - поєднання даних з різних часових осей (дата створення акаунту vs дата відправлення email)
- **Window Functions** - DENSE_RANK для рангування країн
- **Агрегування** - розраховування сум та підрахунків на різних рівнях деталізації

## Використання

Запит можуть бути виконаний в BigQuery або інших SQL базах даних, які підтримують аналогічний синтаксис. Результати дозволяють:
- Визначити найбільш активні ринки за користувачами та email-взаємодією
- Аналізувати эффективність email-маркетингу по геграфіям
- Отримувати топ-10 країн з найвищою активністю
- Аналізувати кореляції між верифікацією та активністю користувачів
